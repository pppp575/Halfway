# Halfway

A daily geography game I made. You get two cities and have to tap the spot exactly halfway between them, along the route a plane would actually fly.

Sounds easy. It isn't, because the Earth is round and flat maps lie. Halfway between London and Tokyo is up in northern Siberia, not over India where most people tap.

Five rounds a day, same cities for everyone. After each round the map folds into a globe so you can see where you went wrong. There's a daily leaderboard, private leagues you can start with friends, and a hard mode if the city dots feel like cheating.

**[Play it here](https://pppp575.github.io/Halfway/)**, it works on phones too.

## Running it yourself

Run `npm install` and then `npm run dev`. The leaderboard needs a free Supabase project; setup notes are in the `docs` folder.
