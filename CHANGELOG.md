# Changelog

Versions follow [Semantic Versioning](https://semver.org).

## 1.0.0

First public release.

- Five daily rounds from a two-year committed schedule, plus archive and practice modes.
- Split-flap round board, flat-map play, flat-to-globe reveal and plane flight.
- Supabase backend with anonymous sign-in, server-side scoring, daily and all-time leaderboards, crowd pins and private weekly leagues.
- Hard mode, ten badges, stats and streaks, light and dark themes.
- Text and image sharing.
- Installable web app with offline support and self-hosted fonts.
- Optional AdSense slots.
- CI and GitHub Pages deploy workflows, unit tests, ESLint and Prettier.
